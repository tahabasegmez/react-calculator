# Calculator

A full-stack calculator with the behavior of the Windows 11 Calculator in Standard mode:
a Go backend performs all arithmetic, and a React + TypeScript frontend handles input and display.

> Work in progress. The full specification is in [docs/SPEC.md](docs/SPEC.md).
